01 / Research

Better detection.
Fewer false alarms.

Lightweight models are useful only if they detect the attacks that matter. My current work examines that trade-off.

Master Project 4 · Ongoing · Unpublished

Proactive Network Defence

A lightweight machine learning system using the NSL-KDD dataset.

The approach

Compare classical classifiers on network traffic features, including Logistic Regression, LDA, Decision Tree, Random Forest, and XGBoost. Select models around false-positive rate and attack recall—not accuracy alone.

  • Official KDDTest+ evaluation split, rather than a random train/test split.
  • Leakage-safe preprocessing: 41 raw features → 122 encoded → 35 selected.
  • Attention to training time, inference throughput, and model size.

Preliminary findings

Binary Random Forest false-positive rate
~1.84%
R2L recovery in the current baseline
~4%
U2R instances recovered
0 / 67

Results reported from the current NSL-KDD baseline. Low false-positive rate does not imply reliable rare-attack detection.

The next research question

How can rare-attack recall improve without making the alert stream too noisy to use?

Planned directions include rare-class augmentation, modern benchmarks, alert explainability, and streaming or edge deployment.
