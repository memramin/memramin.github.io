Primary Agenda

Research Focus

Proactive Network Defence with Lightweight ML (Master Project 4 — ongoing)

Working title: Proactive Network Defence: A Lightweight Machine Learning System Using the NSL-KDD Dataset
Supervisor: Prof. Sameera Abar · KCGI · Master Project 4 (in progress, unpublished draft)

Evaluating classical ML models (Logistic Regression, LDA, Decision Tree, Random Forest, XGBoost) for intrusion detection on tabular network traffic features — explicitly preferring interpretable, deployable models over opaque deep architectures for this operational setting.

Method choices that matter
  • Evaluation on the official, distribution-shifted KDDTest+ split (22,544 records), rather than a misleading random train/test cut.
  • Leakage-safe feature pipeline: 41 raw features → 122 encoded → 35 selected, executing in under one second.
  • FPR-first model selection rather than accuracy alone, prioritizing operational viability.
Preliminary results (honest)
  • Recommended binary model: Random Forest at ~1.84% false-positive rate.
  • Lightweight deployment metrics (training time, inference throughput, on-disk model footprint) are rigorously tracked.
  • Rare classes remain unsolved: R2L recovery is only about 4%; 0 of 67 U2R instances are recovered in the current baseline (alerts that fire remain high-precision). That failure — not the FPR headline — is the exact research question I want to carry into a kenkyusei / PhD lab.

Intended next steps (continuity into doctoral work): Rare-class data augmentation, evaluation on modern domain-specific benchmarks, alert explainability, and streaming/edge deployment under strict low-FPR constraints.
